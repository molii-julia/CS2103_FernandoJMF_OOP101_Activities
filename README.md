OOP101 Activities

This repository only contains a collection of activities from our Object-Oriented Programming (OOP) course in Computer Science.

About:
Each folder/file here represents an activity, exercise, or sample program completed as part of the course. They cover different Java and OOP concepts such as classes, data types, string handling, and basic programs used for practice.

Contents:
Some of the topics covered in these activities include:

Classes and objects (e.g. Characters)
Data types and conversions (e.g. FloatData, KmtoMeter)
String handling and comparison
Basic sample programs

Notes
This repo is mainly for learning purposes and tracking progress throughout the course.
